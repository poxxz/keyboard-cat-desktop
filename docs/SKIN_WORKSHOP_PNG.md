# 皮肤工坊 · PNG 贴图进阶方案 (`feat/skin-workshop-png`)

基于 `v1.7.3` 分支构建的进阶皮肤工坊，在保留原有 8 只内置矢量猫咪、键盘/鼠标/手柄交互、密码防偷窥与动态情绪系统的基础上，完整支持 **分层透明 PNG 贴图导入、实时动画预览与 `.kcat` 皮肤包分享**。

## 核心特性

1. **8 层独立透明 PNG 槽位（支持任意局部替换）**
   - `head.png`：头部常态贴图（自动跟随呼吸、视线转头、前倾、蹲伏与趴睡）
   - `head_blink.png`：闭眼/趴睡/密码防偷窥自动切换头部（可选）
   - `head_angry.png`：连续高速敲键触发愤怒时自动切换头部（可选）
   - `body.png`：身体躯干贴图（自动随前倾剪切、蹲伏和趴睡压扁形变）
   - `tail.png`：尾巴贴图（以左下方尾根为支点动态摆动，情绪越急摇得越快）
   - `paw_left.png` / `paw_right.png`：左右爪/前臂贴图（未单独导入右爪时默认自动水平镜像左爪）
   - `accessory.png`：头饰/挂件贴图（帽子、蝴蝶结、墨镜、耳机等，叠在头部最前层同步运动）
   - **混合底模机制**：未导入 PNG 的槽位自动沿用所选底模猫咪（支持全部 8 只内置猫，含长毛虎斑与短尾三花），只导入一张头饰或猫头也能立刻生效。

2. **进阶动画与渲染模式**
   - **眼睛驱动模式**：支持「纯 PNG 表情切换」或「叠加动态追踪眼」（在 PNG 头部上叠加 40fps 鼠标追踪瞳孔、眨眼与愤怒眉眼，可调高度/眼距/大小/虹膜色）。
   - **手臂与爪子模式**：
     - `弹性臂 + PNG 爪尖`（推荐）：保留自然弯曲的贝塞尔前臂（支持自定义毛色及**一键从身体/头部 PNG 自动吸色**）+ 爪尖贴图随手腕角度微倾和敲键压扁。
     - `整臂 PNG 拉伸`：从肩部锚点旋转并拉伸整条手臂贴图至目标按键/鼠标/手柄。
     - `仅底模手臂`：保留内置底模前臂。
   - **像素画锐利缩放**：支持切换 `NearestNeighbor` 像素画模式与 `HighQuality` 插画模式。
   - **动态情绪特效开关**：可自由保留或关闭流汗、呼吸灯愤怒符号、闲置 Zzz 与胡须叠加。

3. **所见即所得交互式皮肤工坊**
   - **实时预览舞台**：支持奶油/透明棋盘格/深色 3 种背景切换，提供 8 种动画一键测试（常规、打字、眨眼、流汗、愤怒、趴睡、抓虫、手柄）。
   - **直接操作**：支持从资源管理器直接拖入 PNG/JPG/BMP 或 `.kcat`/`.zip` 文件；开启辅助框后可在预览区直接鼠标拖拽定位、滚轮缩放。
   - **创作者工具**：
     - **导出 PNG 绘画模板**：一键导出 5 张 4x 高清透明底稿（含底模半透明参考轮廓与支点准星）与制作说明。
     - **从底模提取 PNG**：可将任意内置猫咪栅格化为 6 张高清透明 PNG 放入皮肤目录，方便用 PS / Procreate / Aseprite 二创后点击「重载」热更新。
     - **一键生成示例头饰 PNG**：内置蝴蝶结、皇冠、墨镜、耳机、巫师帽 5 种透明 PNG 生成器，无需准备素材即可直接体验贴图叠加与定位。

4. **本地存储与 `.kcat` 皮肤包**
   - 皮肤目录：`%LOCALAPPDATA%\KeycatDesktop\skins\<skin-id>\`（内含 `skin.xml` 与独立拷贝的 PNG 文件，原文件删除或移动不影响使用；加载到内存不锁定磁盘文件，支持热重载）。
   - `.kcat` 皮肤包：标准 ZIP 归档（含 `skin.xml` + `*.png` + `256×256` `preview.png`），支持安全校验（路径穿越防护、体积与数量限制）及纯 PNG 压缩包自动槽位识别。

## 架构新增与变更文件

| 文件 | 说明 |
| --- | --- |
| `windows/app/CustomSkin.cs` | 8 槽位图层配置、动画/风格参数、XML 序列化、无锁内存 PNG 加载、主色吸取算法 |
| `windows/app/CustomSkinRenderer.cs` | 分层 PNG 合成渲染引擎、动态追踪眼叠加、弹性臂/整臂模式、头饰与辅助框绘制 |
| `windows/app/SkinManager.cs` | 本地皮肤库 CRUD、图片归一化导入、`.kcat` 打包/解包、4x 模板导出、底模提取、示例头饰生成 |
| `windows/app/SkinWorkshopWindow.cs` | 三栏 2K 奶油风皮肤工坊窗口（皮肤库 / 实时预览舞台 / 图层与动画风格编辑） |
| `windows/app/Preferences.cs` | 持久化 `customSkinId`（向后兼容 1.7.3 配置，皮肤删除时自动回退至内置猫） |
| `windows/app/CatScene.cs` | 桌宠渲染与摸头命中检测接入 `CustomSkinRenderer` |
| `windows/app/SettingsWindow.cs` | 外观页新增「皮肤工坊 (PNG) →」入口与「我的 PNG 皮肤」快捷切换条 |
| `windows/app/App.cs` | 启动加载皮肤库、管理工坊窗口生命周期与托盘菜单入口、实时同步桌宠 |
| `windows/app/TabbyArt.cs` / `BobtailArt.cs` | 暴露内部部件绘制接口，使长毛虎斑与短尾三花同样支持作为 PNG 皮肤底模 |
| `windows/app/build.ps1` | 新增 `.NET Framework 4.8` 内置 `System.IO.Compression*.dll` 编译引用（仍为单文件零外部依赖 EXE） |
